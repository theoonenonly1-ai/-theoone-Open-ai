# TheOone AI Companion — MVP

Ein schlanker, funktionierender Frontend-Prototyp für die neue TheOone-AI-Companion-Plattform.

## Enthalten
- Home / Companion Dashboard
- Chat-Oberfläche
- lokales Memory mit Löschen
- Companion-Profil
- Basis-Skills
- Control Center
- responsive Smartphone-/Desktop-Oberfläche
- TheOone Black/Red/White Designrichtung

## Bewusst noch nicht in Version 1
- echte KI-API
- Cloud-Memory
- Login/Accounts
- Voice
- Zahlungsabwicklung
- Marketplace
- Gaming-/Konsolenintegration
- AR/VR
- 18+ Erweiterungen

Diese Punkte bleiben spätere, optionale Erweiterungen ab Version 2.0+.

## Test
companion/index.html direkt öffnen oder den Ordner als statische Seite deployen.

## Nächster technischer Schritt
Eine sichere Backend-API zwischen Oberfläche und KI-Modell einbauen. Der API-Schlüssel darf niemals im Browser liegen.
