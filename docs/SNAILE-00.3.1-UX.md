# Natural Companion UX rules

1. Speak normally; no command syntax is required.
2. Short requests receive short answers.
3. Ask one focused clarification only when required.
4. Long-running actions acknowledge start and report completion.
5. Voice can be interrupted.
6. Text and voice share the same context.
7. Technical errors are translated into useful human language.
8. Do not repeatedly ask for information already available in permitted context.
9. High-impact actions require explicit confirmation according to permission policy.
