# Snaile 00.2 — Data Governance

Default: personal conversations are private.

Data may enter collective learning only when the source policy permits it, direct identifiers and unnecessary personal content are removed, the resulting insight is useful beyond one person, and retention/deletion rules are defined.

Training data is separate from operational memory.

Flow:
User -> Private Memory -> Privacy Filter -> Abstract Learning Signal -> Consent Gate -> Collective Learning Store -> Curated Dataset -> Training/Evaluation -> Versioned Model

Never let the learning pipeline silently turn private memories into training data.
