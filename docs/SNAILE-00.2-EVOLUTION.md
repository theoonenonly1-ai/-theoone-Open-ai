# Snaile Engine 00.2 — Companion Evolution

Snaile is designed as a lifelong AI companion platform. Each companion has a life line: memory continuity, learned preferences, personality versions and development stages.

## Separation
- Private Memory: personal memories and relationship context.
- Collective Learning: only privacy-checked, explicitly permitted abstract insights.
- Evolution Dataset: curated training signals for future model/skill versions.
- Model Layer: replaceable, versioned foundation model; never silently self-modified.

## Companion Age
Each instance stores birth timestamp, chronological age, development stage, personality version and life events.

Stages:
1. NEWBORN — curious and explanation-oriented
2. YOUNG — exploratory and fast-learning
3. MATURE — stable character and broader context
4. EXPERIENCED — reflective and consistent
5. ELDER — long biographical continuity and calmer style

Age is a narrative/personality dimension, not a basis for discriminatory decisions.

## Personality
Personality combines an immutable identity core, learned traits, relationship context, life experience and current state. Changes are gradual, versioned and reversible.

## Evolution Loop
Experience -> signal extraction -> candidate change -> simulation -> evaluation -> approval -> versioned adoption.

Security-critical engine code is never directly self-modified.

## Multi-instance learning
Companions may share verified abstract insights. Raw chats, identities, contacts, private files and other personal content remain private by default.

## Consent
Every learning signal carries a policy:
PRIVATE, LOCAL_ONLY, COLLECTIVE_OPT_IN, or TRAINING_OPT_IN.

## Long-term continuity
Identity, important memories, life events and personality versions persist across years and across replacement of the underlying foundation model.

## Goal
TheOone is a concrete companion instance. Snaile Engine provides the platform for identity, memory, personality, learning and controlled evolution across many years.
